How it works: a server bound to localhost behaves as today (no key, the desktop app keeps working). Reaching it from other devices needs a key: from --api-key / GHOST_INFER_API_KEY, or made at first start and printed in the terminal as a sign-in link. Once a key exists, every /v1 and /api request needs one, from localhost too, because tunnels arrive as localhost. Browsers trade the key for a cookie once; apps send Authorization: Bearer.
