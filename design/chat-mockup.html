Write a Python function that checks whether a string is a palindrome, ignoring spaces and punctuation.

Thought for 2.4 s
The user wants letters and digits only, compared case-insensitively. Filter with str.isalnum, lower-case, then compare with the reverse. Mention that it handles an empty string.

Keep only letters and digits, ignore case, then compare the cleaned string with its reverse:

Python
def is_palindrome(text: str) -> bool:
    cleaned = [c.lower() for c in text if c.isalnum()]
    return cleaned == cleaned[::-1]

print(is_palindrome("A man, a plan, a canal: Panama"))  # True

An empty string counts as a palindrome, since it reads the same both ways. If you only want letters, swap isalnum() for isalpha().
